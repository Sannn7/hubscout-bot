# hubscout-bot
HubScout is an agentic AI + RAG assistant that answers questions about neighborhoods, transit, property, construction, and local context by combining:
- **offline structured datasets** (cleaned + modeled for analytics),
- **retrieval over documents** (RAG),
- and **real-time web/news tools** when users ask time-sensitive questions.

The end goal is a **production-grade, cloud-deployed system** with monitoring, logging, evaluation, and CI/CD.
